# Азкары

Утренние и вечерние азкары: арабский текст, перевод, транскрипция и счётчик повторов.
Работает в браузере и ставится на телефон как приложение.

## Как установить на iPhone

1. Открыть https://mayrcod.github.io/azkar/ в Safari.
2. «Поделиться» → «На экран „Домой“» → «Добавить».

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Всё приложение: разметка, оформление, логика и тексты азкаров (список `AZKAR`) |
| `sw.js` | Работа без интернета. При каждом обновлении приложения увеличивать `VERSION` |
| `manifest.webmanifest` | Название, иконка и цвета для установки на телефон |
| `icon-*.png`, `apple-touch-icon.png` | Иконки |
| `.nojekyll` | Говорит GitHub Pages отдавать файлы как есть |

## Источники

Тексты азкаров: azkar.ru. Номера хадисов сверены по sunnah.com.
Арабский шрифт: KFGQPC HAFS Uthmanic Script (Комплекс короля Фахда), встроен без изменений.
