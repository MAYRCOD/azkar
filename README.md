# Азкары

Утренние и вечерние азкары: арабский текст, перевод, транскрипция и счётчик повторов.
Работает в браузере и ставится на телефон как приложение.

**Открыть:** https://mayrcod.github.io/azkar/

## Как установить на iPhone

1. Открыть ссылку выше в Safari.
2. «Поделиться» → «На экран „Домой“» → «Добавить».

## Как устроен проект

```
azkar/
├── index.html            ← готовое приложение (собирается, руками не править)
├── sw.js                 ← работа без интернета; VERSION меняется при каждой публикации
├── manifest.webmanifest  ← название и иконка для установки на телефон
├── icon-*.png, apple-touch-icon.png  ← иконки (делаются из src/logo/logo.svg)
├── src/                  ← ИСХОДНИКИ: всё правится здесь
│   ├── app.html          ← разметка, стили, логика и тексты азкаров (список AZKAR)
│   ├── pwa-head.html     ← «шапка» страницы для телефона
│   ├── fonts/            ← шрифты (встраиваются в index.html при сборке)
│   ├── images/           ← картинки для кнопок утро/вечер
│   └── logo/logo.svg     ← логотип (векторный, из него делаются иконки)
├── tools/build.py        ← сборка: src/ → index.html
├── tools/make_icons.js   ← иконки из логотипа
└── tests/                ← проверки в настоящем браузере
```

Почему так: `index.html` — один большой файл, в который встроены шрифты и картинки
(так приложение работает без интернета). Править его неудобно, поэтому правки
вносятся в `src/app.html`, а `index.html` собирается из него командой.

## Как внести изменение

```bash
# 1. Поправить src/app.html
# 2. Собрать (номер версии — на 1 больше прежнего)
python3 tools/build.py --version 4
# 3. Проверить (первый раз: cd tests && npm install)
bash tests/run.sh          # должно закончиться «ВСЁ В ПОРЯДКЕ»
# 4. Сохранить и опубликовать
git add -A && git commit -m "Что поменялось" && git push
```

Через минуту-две GitHub Pages обновит сайт, а телефон подтянет новую версию
при следующем открытии приложения с интернетом.

## Как поменять логотип

Поправить `src/logo/logo.svg` и пересоздать иконки:

```bash
NODE_PATH=tests/node_modules node tools/make_icons.js
python3 tools/build.py --version <следующая>
```

На iPhone иконка запоминается при добавлении на экран «Домой» — чтобы увидеть
новую, приложение нужно удалить с экрана и добавить заново.

## Что проверяют тесты

Главная и настройки; оба вида чтения и переключение между ними; все утренние (16)
и вечерние (15) азкары до конца; сброс; отступы, спрятанная полоса прокрутки и
номера аятов на трёх ширинах экрана; смена дня в полночь; работа без интернета;
иконки (загружаются, правильные размеры).

## Источники и лицензии

- Тексты азкаров: azkar.ru. Номера хадисов сверены по sunnah.com.
- Арабский шрифт: KFGQPC HAFS Uthmanic Script (Комплекс короля Фахда). Распространяется
  бесплатно, без изменений — см. `src/fonts/KFGQPC-COPYRIGHT.txt`.
- Русский шрифт: Nexa (Fontfabric) — платный. Перед публичным распространением
  нужна лицензия или замена на бесплатный шрифт.
